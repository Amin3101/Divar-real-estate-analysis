# آنالیز دیتاست دیوار

این پروژه یک کار گروهی برای تحلیل دیتاست آگهی‌های دیوار است. در این پروژه آمار توصیفی، آزمون فرض و یک بخش مدل‌سازی (سیستم پیشنهادگر یا مدل پیش‌بینی) انجام شده است.

## اعضای تیم و تقسیم کار

| عضو تیم | آمار توصیفی (سؤال‌ها) | آزمون فرض (سؤال‌ها) | بخش مدل‌سازی |
|---|---|---|---|
| علی ارشیا خویش‌خواه | ۲، ۶، ۷ | ۲ | سیستم پیشنهادگر |
| محمدامین مرادقلی | ۱، ۸، ۹ | ۳، ۴ | سیستم پیشنهادگر |
| هیربد رحمانی | ۳، ۴، ۵ | ۱ | مدل پیش‌بینی |

## محتوای پروژه

### ۱. آمار توصیفی
در این بخش، ویژگی‌های اصلی دیتاست (مانند میانگین، میانه، پراکندگی و توزیع متغیرها) بررسی و با نمودار نمایش داده شده است. سؤال‌های این بخش بین اعضای تیم طبق جدول بالا تقسیم شده‌اند.

### ۲. آزمون فرض
در این بخش، فرضیه‌های مربوط به داده‌های دیوار با روش‌های آماری آزمون شده‌اند. هر آزمون شامل بیان فرض صفر و فرض مقابل، انتخاب آزمون مناسب، محاسبه مقدار p و نتیجه‌گیری است.

### ۳. سیستم پیشنهادگر
سیستمی که با توجه به ویژگی‌های آگهی‌ها یا رفتار کاربران، آگهی‌های مشابه یا مرتبط را پیشنهاد می‌دهد.

### ۴. مدل پیش‌بینی
مدلی که با استفاده از ویژگی‌های آگهی، یک متغیر هدف (مثلاً قیمت) را پیش‌بینی می‌کند و با معیارهای ارزیابی مناسب سنجیده می‌شود.
